# acct_tools

すべてブラウザで直接開ける単一 HTML ファイルです。ビルド不要・依存ライブラリなし。

## 使い方

1. リポジトリをクローンまたは ZIP ダウンロード
2. `src/` 内の HTML ファイルをブラウザで直接開く

```bash
git clone https://github.com/fetofeto2-lab/acct_tools.git
cd acct_tools/src
# ブラウザで開く（例: macOS）
open Furusto_Rimit_tax.html
```

サーバー不要。インターネット接続は Google Fonts の読み込みのみに使用します。

## 各ツールの詳細

### ふるさと納税 寄付上限額 算定ツール v2

給与収入または住民税所得割額を入力するだけで、ふるさと納税の自己負担 2,000 円となる上限額を自動計算します。

**計算ロジック**
```
上限額 = 住民税所得割額 × 20% ÷ (0.9 − 所得税率 × 1.021) + 2,000円
```

- テーマ: ダーク（ゴールド / ネイビー）
- 2 つの入力モード: 給与収入入力 / 住民税額直接入力

---

### 法人版 利子所得税 計算シート v4

定期預金などの利子に対する源泉徴収税額（15.315%）を双方向で計算します。

**計算ロジック**
```
利子所得税率 = 15.315%（所得税 15% + 復興特別所得税 0.315%）
差引入金額 → 税引前利息: 入金額 ÷ (1 − 0.15315)
税引前利息 → 差引入金額: 利息 × (1 − 0.15315)
```

- テーマ: ライト（ブルー / ホワイト）
- 複数行の一括入力に対応

---

### 手取り逆算ツール | 給与計算 v3

社会保険料・源泉所得税・住民税を考慮した正確な手取り計算と逆算を行います。

**対応計算**
- 総支給額 → 手取り額
- 希望手取り額 → 必要総支給額（逆算）

**考慮項目**
- 健康保険料（標準報酬月額テーブル参照）
- 厚生年金保険料
- 雇用保険料
- 源泉所得税（扶養親族数考慮）
- 住民税

- テーマ: ライト（クリーム / グリーン）

---

### 法人税・地方税 概算計算ツール v1

中小企業（資本金1億円以下）の所得金額から、法人税・地方法人税・法人住民税・法人事業税・特別法人事業税の概算年税額を算出します。

**対応内容**
- 事業年度切替: 令和7年4月1日開始年度 / 令和8年4月1日以降開始年度（年度マスタで拡張可能）
- 対象自治体（都道府県マスタで拡張可能）
  - **宮城県**: 仙台市（区単位で選択）・名取市・富谷市・岩沼市・多賀城市・東松島市（＋標準税率市町村）
  - **長野県**: 長野市・上田市（＋標準税率市町村）
- 県ごとの超過課税に対応（宮城県：みやぎ発展税・みやぎ環境税／長野県：森林づくり県民税、事業税は標準税率）
- 市の超過課税に対応（長野市：法人税割7.1%・7.7%・8.4%／均等割 標準の1.2倍、上田市：法人税割7.4%一律／均等割は資本金等1億円超が1.2倍）
- 最大5事業所（本店含む）に対応。**都道府県をまたぐ事業所配置も計算可能**
  - 2以上の市町村: 市民税法人税割を従業者数で按分（地方税法321条の13）、均等割は各市で課税
  - 2以上の都道府県: 県民税法人税割・事業税も従業者数で按分（地方税法57条・72条の48）、県均等割は各県で課税
  - 事業税の軽減税率（年400万円・800万円の区分）は分割後の各県の課税標準に適用。超過課税（みやぎ発展税等）の判定は分割前の所得の総額で実施
  - 資本金1,000万円以上で3以上の都道府県に事務所がある場合は軽減税率不適用（地方税法72条の24の7）を自動判定
- 仙台市は政令指定都市のため均等割は区ごとに課税（従業者数50人超の判定も区ごと・地方税法737条）。法人税割は市単位で計算
- 繰越欠損金・交際費（定額控除800万円 / 接待飲食費50% の有利判定）・その他加算減算に対応
- みやぎ発展税・みやぎ環境税・超過税率（法人税額1,000万円超）の自動判定
- 均等割（資本金等の額 × 従業者数区分）を含む実納税額に近い概算
- 防衛特別法人税 4%（令和8年4月1日以後開始事業年度・基礎控除500万円）に対応
- 予定納税額（中間納付額）の入力で差引最終納付額・還付見込額を算出（未入力時は考慮しない）
- A4 印刷 / PDF 出力（顧問先配布用の税額計算書様式）

- テーマ: ライト（ブルー / ホワイト）

### 借入金 返済予定表 作成ツール v2

法人が銀行等から融資を受けた場合の返済予定表（返済明細）を、実際の返済日に基づく実日数日割り計算で作成します。

**計算ロジック**
```
利息（毎回）= 前回返済日からの経過日数 × 前回元金残高 × 年利率 ÷ 365日（円未満切捨て・年365日固定）
元利均等: 毎回返済額 = P × r ÷ (1 − (1+r)^−n)（r=月利, n=元金返済回数。実日数利息を差し引いた額を元金に充当）
元金均等: 毎回元金 = P ÷ n（端数は最終回で調整）
```

**対応内容**
- 返済日（毎月1〜31日 / 未指定は月末）を指定可能。31日等その月に存在しない日は月末に繰上げ
- 借入日・返済日から、実際の返済日を基準とした実日数（前回返済日〜今回返済日）で利息を日割り計算
- 借入日入力時、借入日以降で最初に到来する返済日の月を初回返済年月に自動セット
- 返済方法: 元利均等 / 元金均等 の切替
- 据置期間（元金返済なし・利息のみ支払）に対応（借入期間の内数）
- 年度別集計: 決算月を指定し、事業年度ごとの元金返済額・支払利息・期末借入金残高を集計
- 法人名・借入先・摘要の任意入力（印刷帳票に反映）
- A4 印刷 / PDF 出力（複数ページ対応・全明細の印刷有無を選択可能）

- テーマ: ライト（ブルー / ホワイト）

---

### 借入金 返済予定表 作成ツール v1（旧版）

利息を「元金残高 × 年利率 ÷ 12（月割り概算・円未満切捨て）」で計算する旧版。返済日の指定には対応していません。実日数での日割り計算が必要な場合は v2 をご利用ください。

### ツール早見表（A4 1 枚・QR コード一覧） v1

各ツールの GitHub Pages URL を QR コード化し、アイコン・ツール名とともに A4 1 枚にまとめた印刷用ページです。顧問先のデスクや掲示物に貼ることで、スマートフォンから直接ツールを開けます。

- 5 ツール分を A4 1 枚に集約（縦並びの一覧レイアウト）
- QR コードは URL から静的生成（外部サービス・実行時通信なし）
- [`qr_codes_v1.pdf`](src/qr_codes_v1.pdf) をそのまま印刷可能（ブラウザを開かず配布・印刷したい場合はこちら）
- テーマ: ライト（ブルー / ホワイト）
